```markdown
## 二级标题

普通段落。**加粗**、*斜体*、`行内代码`。

- 列表项一
- 列表项二

1. 有序项
2. 有序项

> 引用：适合放结论或原文摘录。
```

## 代码块

三个反引号加语言名，就会有语法高亮：

```python
def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## 表格

| 写法 | 效果 | 用途 |
| --- | --- | --- |
| `**字**` | **字** | 强调关键词 |
| `` `代码` `` | `代码` | 行内术语 |
| `[文字](链接)` | [文字](https://example.com) | 跳转 |

## 数学公式

行内公式用一对 `$`，块级公式用两对。比如 `$O(n \log n)$` 会渲染成 $O(n \log n)$。

块级公式：

$$
T(n) = 2T\left(\frac{n}{2}\right) + O(n) = O(n \log n)
$$

## 图片

把图片放进 `public/images/`，然后用 `![](/images/文件名.png)` 引用。前面那段英文是图片描述，别忘了写。

## 一个小提醒

标题只用 `##` 和 `###`。文章大标题（`#`）由页面的 front matter 里的 `title` 决定，正文里再写一个 `#` 会出现两个主标题。
