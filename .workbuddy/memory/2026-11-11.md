## 个人博客（学习档案）搭建

**定位**：公开的学习档案库，不是面向读者的博客。主要读者是作者本人，更新频率不定，内容混杂长文与碎片笔记。

**技术栈定案**：Astro 6.4.8 + Markdown 内容集合 + GitHub Pages（用户主动选择 Pages 而非 Cloudflare Pages），remark-math + rehype-katex 支持公式。

**环境约束（重要）**：本机 Node 由 WorkBuddy 托管，仅 22.22.2 可用，而 Astro 7 硬性要求 >=22.23.4 会直接拒绝启动。因此主动把 Astro 钉在 ^6.4.8（要求 >=22.12.0）。判断原则：让项目适配机器，不让机器迁就框架。GitHub Actions 里用 node 22（会自动取最新 22.x）。

**已完成的实现**（工作区根目录即项目根）：
- `src/content.config.ts`：posts（title/description/date/tags/draft）+ notes（title 可选）两个集合
- `src/lib/content.ts`：排序、草稿过滤（DEV 可见、构建隐藏）、日期固定按 Asia/Shanghai 输出、阅读时长、标签统计
- 路由：`/` 时间线（长文与笔记混排）、`/posts/[...id]`、`/notes/[...id]`、`/tags/`、`/tags/[tag]`、`/about`、`/404`、`/rss.xml`
- `src/styles/global.css`：单栏 44rem、暖色中性调、正文 1.9 行高，body flex + main flex:1 保证页脚贴底
- `.github/workflows/deploy.yml`：显式 setup-node 22 + npm ci + upload/deploy-pages（没用 withastro/action，避免 action 版本与 Astro 大版本不匹配）
- `README.md`：面向零前端基础的操作手册

**约定**：长文文件名用英文 slug 不带日期（会进 URL，一次定终身）；短笔记文件名 YYYY-MM-DD-slug；标签名不含 `/`。

**验证方式**：`npm run build` 生成 19 页；用 puppeteer-core 附着本机 Edge 在 1280/390 两个视口测 scrollWidth 确认无横向溢出；构建警告（markdown.remarkPlugins 弃用）改用 `unified()` 从 @astrojs/markdown-remark 传入后消除。

**踩坑记录**：Edge `--window-size=390` 截图不会应用移动端视口，会得到"内容被截断"的假象，必须用 CDP 设置 viewport 才能真实测移动端。

## 网络环境（重要，反复卡住的地方）

- 系统代理：`127.0.0.1:12300`（HTTP 与 SOCKS5 都可用，git ls-remote 实测两种方式均通）
- **github.com 直连不可用**：TLS 被中途掐断（GnuTLS recv error -110 / CONNECT timeout）；api.github.com 反而可直连
- Windows 侧 git 已配置全局 `http.proxy` / `https.proxy` 指向 12300
- WSL 不继承 Windows 系统代理，需单独 `git config --global http.proxy`；若代理只监听回环还需开「允许局域网连接」
- 认证：GitHub 已禁用密码，必须用 PAT；因仓库含 workflow 文件，token 必须同时勾 **repo + workflow**

**写作教训**：README 命令里用 `<你的用户名>` 当占位符，用户照抄导致 bash 把 `<` 当重定向报 `No such file or directory`；已改为不带尖括号并加显式警告。给非技术用户的占位符不要用尖括号。
